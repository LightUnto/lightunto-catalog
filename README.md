# LightUnto catalog

This is the public list of resources LightUnto knows about. Each hosted item records its title, source URL, license, proof link, and the date the metadata was taken. The skipped list records works that are not hosted, with the reason.

The file is metadata only. It does not include Bible text, commentary text, or book text.

This repository is [CC0 1.0](LICENSE). The licenses of the works named here are recorded on each item and are separate from this catalog.
